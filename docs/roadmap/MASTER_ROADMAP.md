# RundaTech Master Roadmap

## Phase 0 — Foundation
- repository structure and coding standards
- CI/CD baseline
- containerization
- PostgreSQL migrations
- authentication/user lifecycle
- RBAC + audit
- secrets/runtime configuration
- backup/restore baseline
- OpenTelemetry baseline

## Phase 1 — Canonical Catalog MVP
- brands/categories/products/variants/spec schema
- source/evidence model
- admin catalog workflow
- record revisions/corrections
- product pages + structured metadata
- search and filters
- initial laptop catalog

## Phase 2 — Comparison + Market Layer
- comparison engine
- markets/domains/currencies
- Kenya domain configuration as first market
- offers/retailers/pricing observations
- price freshness and history UI

## Phase 3 — AI-Assisted Data Operations
- AI gateway
- prompt registry
- extraction pipeline
- source conflict detection
- duplicate/entity resolution suggestions
- evaluation suite
- reviewer console

## Phase 4 — Automated Pricing
- retailer adapter framework
- scheduler/queues
- price normalization/anomaly controls
- connector monitoring/circuit breakers
- affiliate feeds where available

## Phase 5 — Editorial Platform
- reviews/guides/news CMS workflow
- product-linked content blocks
- evidence-aware AI drafting
- author/reviewer attribution
- SEO/internal linking automation with review

## Phase 6 — Regional Expansion
- `.com`, `.ug`, `.tz` domain registry
- UG/TZ retailers/currencies/localization
- market-scoped staff permissions
- country launch checklist

## Phase 7 — AI-Native RundaTech
- grounded “Ask RundaTech” assistant over verified catalog/pricing/content
- personalized comparison/finder workflows
- tool-based product reasoning
- AI safety/evaluation monitoring

## Phase 8 — Platform / Partner APIs
- public/partner APIs
- API keys, quotas, usage metering
- retailer data ingestion APIs/webhooks
- export/data licensing controls

## Do not prematurely build
- dozens of microservices
- Kubernetes solely for fashion
- multi-region active-active database before demand
- custom authentication cryptography
- autonomous AI with production write/admin privileges
